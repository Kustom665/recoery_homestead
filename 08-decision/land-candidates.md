# Land Candidates — Real Listings, Kill-Test Status

Pulled 23 Oct 2026 from public listing sites. **Listings go stale in days.**
Every entry needs a live check before you call anyone. Prices are asking, not
sold.

Read this with `02-land/parcel-due-diligence.md` open. The four kill tests
there are: **0 — who actually zones it**, **1 — will it perc**, **2 — carbonate
geology / nitrate**, **3 — easements and Clean & Green**. Nothing here has had
a perc test. Nothing here has had a title search. "Pass" below means the
desk-check passed; it never means buy.

## What changed since `02-land/county-shortlist.md`

That document ranked counties for **buying raw land and building**. Two
findings this round narrow it:

1. **For the year-one leased house, county ranking is moot.** You lease within
   90 minutes of Berks. See `ceo-decision.md` section 6.
2. **For the year-two purchase, Wyoming County joins the list.** No county
   zoning; Meshoppen Township is on the county's own unzoned list; and it has
   the single best farmhouse-plus-acreage comparable found in the region.
   Bradford County has the cheapest acreage. Susquehanna's farmhouse listings
   are priced for the river, not the farm.

The Land.com median for Susquehanna came back at **~$7,558/acre** this round,
below the ~$9,300 sold-record median in `county-shortlist.md`. Both are small
samples. Budget off the higher number.

### Meshoppen, Wyoming County — 54.25 ac, farmhouse + barn, $275,000

| | |
| --- | --- |
| Listing | 0 State Route 3001, Meshoppen, PA 18630 — Acrevalue, dated 15 Sept 2026, marked active |
| Price/acre | ~$5,070 |
| Structures | Farmhouse and barn, **both need substantial work** (listing's words). Fields currently hayed. |
| Kill test 0 — zoning | **Pass (desk).** Wyoming County has no countywide zoning. Meshoppen Township is on the county's 2013 list of municipalities without a zoning ordinance; the 2014 county map agrees. **Confirm with the township secretary in writing — the list is 13 years old.** |
| Kill test 1 — perc | Unknown |
| Kill test 2 — geology | Unknown. Wyoming County is largely shale/sandstone, not limestone — favorable, unverified. |
| Kill test 3 — easements / C&G | Unknown. "Fields hayed" suggests possible Clean & Green enrollment — **ask before offering**. |
| Road | State Route frontage → **PennDOT Highway Occupancy Permit** for a new driveway. Existing driveway may be grandfathered. Check. |
| Ch. 717 fit | A fixer farmhouse. Rehab to pass § 717.29 (60 sq ft/resident, egress, kitchen, ≤120°F water) is **$40–80k, a guess until walked**. |
| Verdict | **The best Path B comparable in the region.** Price is right, zoning is right, county is cheap. The rehab number is the whole question. Walk it with a contractor before anything else. |

Note the ZIP: two ZIP-code sites list 18630 as Susquehanna County. **It is
Wyoming County.** Wikipedia, TopoQuest, and the county's own site agree.

## Not land — but it affects every parcel above

**Harvest Hosts changes how you scout.** A $99 Classic membership gives a
year of free overnight stays at ~398 Pennsylvania host farms, wineries, and
breweries. There are hosts near Susquehanna (SnowMarsh Farm, Endless
Mountains) and in Bradford (a Canton winery). Use it to sleep in the target
counties on weekends, talk to the farm owners who host, and ask each one the
Jacob's Ladder question: *"Would you partner with a recovery program that
worked your land?"* That is how Brookside Farm actually runs — the Utterback
family owns it, the program works it. One yes replaces the whole Path B down
payment.

**Condition:** Harvest Hosts stays require a **self-contained RV** — onboard
toilet and water. If the construction-phase campers in
`04-architecture/camper-phase.md` are meant to double as your scouting rig,
spec them that way. A camper without a bathroom does not qualify.
